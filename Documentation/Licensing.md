# Licensing

>   [!IMPORTANT]  
>   Before adding materials to this repository check the source license.
>   Some sources, such as [MatWeb](https://matweb.com/) allow you to use the information for personal use but do not allow redistribution.  
>   → _**DO NOT**_ add materials where the source materials do not allow redistribution.

Each material specifies its own license. These licenses should allow for unrestricted use, copying, and redistribution. Contributors are responsible for ensuring these conditions are met.

A good license choice is the CC-BY-SA-4.0 license. You can read the terms of this license [here](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en).
