# Adding Materials

>   [!IMPORTANT]  
>   Before adding materials to this repository check the source license.
>   Some sources, such as [MatWeb](https://matweb.com/) allow you to use the information for personal use but do not allow redistribution.  
>   → _**DO NOT**_ add materials where the source materials do not allow redistribution.
>   
>   In many cases the source materials are not the original references. Refer to those as they often have more permissive license conditions.

## Adding a new material

* Clone the repository
* Create a new branch in your local repository
* Add your material
* Create a Pull Request to have your changes reviewed and accepted

## Tips for creating a good material

* Be descriptive! Fill in the description fields to the best of your ability
* Quote your references. This will allow users to assess the quality of the data.
* Use the standard models defined by FreeCAD as much as possible. Applications need to know how the data is organized in order to use the information. Non-standard models generally won't be used.
